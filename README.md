# CRAVE

Full stack app:
- Backend: FastAPI
- Frontend: React / Expo

See `CRAVE_STATUS.md` for current status, test counts, and the
prioritized backlog. See `CRAVE_REMAINING_WORK.md` for the detailed,
dated log of every fix made. See `docs/doctrine/` for the product vision.

## Setup

Backend:
cd backend
pip install -r requirements.txt

Frontend:
cd frontend
npm install
npm start

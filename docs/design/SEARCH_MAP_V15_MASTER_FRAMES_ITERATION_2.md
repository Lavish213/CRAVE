# Search / Map V1.5 Master Frames - Iteration 2

Status date: September 7, 2026  
Status: Exploratory visual direction, not implementation-ready  
Prior grade target: 8.1/10 direction  
Purpose: Solve the four master-frame issues before propagating the visual system across all V1.5 states.

## Focus

This iteration intentionally does not expand to all 16 states. It improves the four master frames only.

Targeted fixes:

1. Real photography vs typography fallback.
2. Less boxy reason presentation.
3. Calmer chip and constraint semantics.
4. More CRAVE-specific selected Map card.

## Visual Direction Changes

- The top result uses an original raster food photograph with editorial restaurant identity; the same frame visibly demonstrates a deliberate type-led identity fallback when imagery is missing.
- Reason text becomes part of the content rhythm instead of sitting in a separate explanation box.
- Interpretation chips use one neutral treatment. Accent color is reserved for the chosen answer or the single removable blocker, not distributed across constraint categories.
- Map selection becomes a dark/translucent, asymmetric CRAVE answer surface with a restrained gold edge and a short "Why here" explanation instead of a generic white map card.
- Search and recovery share the same grammar: craving headline -> interpreted constraints -> answer or blocker.

## Still Not Claimed

- Not Penpot implementation-ready.
- Not componentized.
- Not device-verified.
- Not backed by approved reason thresholds.
- Not propagated across the full 16-state inventory.
